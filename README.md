# ryanjohn1.github.io

Personal website for [ryanjohn1](https://github.com/ryanjohn1), published with GitHub Pages.

## Editing the site

Update `index.html` and push to `main`. The **Deploy GitHub Pages** workflow publishes the site automatically.

## First-time setup

In the repository's **Settings → Pages**, set the build and deployment source to **GitHub Actions**. After the first successful workflow run, the site will be available at <https://ryanjohn1.github.io>.
